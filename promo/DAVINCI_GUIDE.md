# Монтаж в DaVinci Resolve

1. До монтажа выбери частоту исходного клипа в **Project Settings → Master Settings → Timeline frame rate**. Для вертикального ролика задай 1080 × 1920. Ассеты по умолчанию сняты в 30 fps, для таймлайна 25 fps можно перерендерить их в 25.
2. Импортируй городское видео и нужный MOV из `out/alpha/` в **Media Pool**. На странице **Edit** положи городское видео на V1, MOV на V2. Видеослои без звука, речь остаётся на аудиодорожке исходного клипа.
3. Проверь **Clip Attributes → Video → Alpha Mode → Straight**, если Resolve показал непрозрачный прямоугольник или кайму. У сцен с сайтом тёмная панель внутри композиции предусмотрена дизайном.
4. В **Inspector → Transform** меняй **Position** и **Zoom**. Для говорящего человека используй свободную сторону кадра. Сохраняй поле у нижнего края для субтитров и проверяй правый край в интерфейсе площадки.
5. Сдвигай слой по форме волны или поставь маркеры на словах «сайт», «проекты» и на произнесённом адресе. При подрезке сохрани первые и последние кадры перехода либо добавь короткий fade в Resolve. Размещай сцены последовательно на V2. Для намеренного пересечения переходов используй V3.
6. **EditorialScroll** и чёрный **FinalWebsiteReveal** из `out/opaque/` работают как полноэкранные перебивки. MP4 из `out/previews/` показывает монтажное превью со сведённым фоном. При проблеме с импортом MOV используй RGBA PNG sequence из команды с `--png`, импортируя серию как один клип.
7. Проверь белый SVG на светлом и тёмном кадрах. Для светлого кадра выбери FinalWebsiteReveal с суффиксом `dark`, для тёмного — `light`. Видео из набора тегировано BT.709. В color-managed проекте проверь назначение SDR Rec.709 для графики, сохрани отдельный input transform для Log/HDR-съёмки и проверь результат по scopes.
8. При финальном экспорте со съёмкой прозрачность сводится с V1. Для переэкспорта отдельно взятого слоя выбери QuickTime ProRes 4444 и включи **Export Alpha**, если этот режим доступен в твоей конфигурации Resolve. Проверь новый файл, наложив его обратно на контрастный фон.
