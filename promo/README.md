# arsenynn.com · The Moving Index

Монтажный набор для вертикального фильма. Источник кадров — локальная сборка сайта из ревизии `ca0d8e908af36ed41e197fb39f257a797b73dc1b`. Playwright снимает страницу в 390 × 694 CSS px, с оригинальным портретом, Manrope, Source Serif 4 и веб-логотипами. Для монтажа реальные секции в браузере захвата упорядочиваются по YAML `order`. Отчёт хранит SHA и деревья исходников и ассетов.

## Первый запуск

Требуются Node.js 22.23.4+, Python 3, FFmpeg и FFprobe. Из корня рабочего дерева:

```sh
npm ci
npm run build
cd promo
npm ci
npx playwright install chromium
npm run capture
npm run render:all
```

Remotion при первом запуске загружает свой Chromium. На Mac Studio перед установкой, сборкой и полным рендером проверь запас диска командой из `AGENTS.md`. После первого захвата команда `npm run render:all` пересобирает весь набор из сохранённых кадров. После правок сайта повтори сборку Astro и захват.

```sh
npm run studio
npm test
npm run render:all -- --scene ProjectFocus --config configs/focus-annflow-25.json
npm run render:all -- --scene WordmarkEmergence --source /path/to/city.mov
npm run render:all -- --scene FinalWebsiteReveal --png
npm run composite -- /path/to/city.mov out/alpha/SCENE.mov out/previews/city-test.mp4 --start 3.5
```

Последняя команда масштабирует и кадрирует копию изображения до размеров слоя, сохраняет дорожку речи в AAC и требует новый путь для результата. Для совпадения кадровой частоты `--source` берёт среднюю частоту из FFprobe, включая дробные NTSC-значения. Для VFR Resolve использует фиксированную частоту таймлайна, которую можно явно задать в JSON.

## Параметры

Выбирай композицию и меняй Props в Studio либо передай частичный JSON. `duration` в секундах, `fps` и `width` / `height` задают метаданные. `x` и `y` — положение центра графики в координатах 1080 × 1920, которое масштабируется под размер кадра. `side` смещает этот центр и меняет сторону входа. `scale`, `opacity`, `speed` — множители. `enter` и `exit` принимают `slide`, `fade`, `cut`. `background` принимает `transparent` или `opaque`.

`project` выбирает секцию в Project Focus. Для Editorial Scroll выбирай `scrollFrom` (`hero` либо slug) и `scrollTo` (slug проекта). `text` управляет адресом и отдельным wordmark в графических сценах. Для панелей `text: false` выбирает отдельный Playwright-захват со скрытым текстом и теми же размерами DOM. `tone` задаёт цвет адреса в финале, `light` для тёмной подложки и `dark` для светлой.

- **subtle** — небольшая амплитуда и короткие фейды.
- **editorial** — остановки в скролле, смена крупности, выдержанный финал.
- **dynamic** — более короткая фаза перехода и больший ход.

## Монтажный ритм

- **Wordmark Emergence**. Оригинальный красный знак входит с края, коротко держит позицию и едва меняет крупность. В комплекте три положения.
- **Floating Website**. Фронтальный кадр мобильного hero с портретом и границей первой секции. Небольшой наезд оставляет пространство человеку справа.
- **Editorial Scroll**. Статичный кадр героя сменяется паузами у разделов. Последовательность начинается с Party Protocol и annFlow, затем идёт по YAML. При короткой реплике задай меньший диапазон.
- **Typography Breakout**. SVG совмещён со своим исходным положением в захваченном hero. Панель гаснет, знак выходит в самостоятельный кадр. Один монтажный скачок делает его крупнее кадра, затем панель возвращается.
- **Project Focus**. Начало секции и узнаваемый знак появляются первыми. Кадр расширяется вниз к описанию и действиям, одновременно приближаясь. Комплект содержит Party Protocol, annFlow и @arsenynn.
- **Final Website Reveal**. Адрес и NN. После входа адрес остаётся статичным почти до конца. В комплекте есть два прозрачных варианта с разным цветом адреса и заставка на чёрном фоне.

## Результаты

`out/alpha/` — MOV ProRes 4444 для V2 в Resolve. `out/opaque/` — полноразмерные MP4. `out/previews/` — MP4 для просмотра, у прозрачных клипов подложка разделена на светлую и тёмную половины. `out/stills/contact-sheet.png` — три кадра каждого клипа, в порядке записей из `out/qa/kit-manifest.json`, слева направо, сверху вниз. Отчёт включает параметры и метаданные FFprobe. Сгенерированные захваты и рендеры игнорируются Git.

См. [инструкцию для Resolve](DAVINCI_GUIDE.md) и [настройки экспорта с прозрачностью в Remotion](https://www.remotion.dev/docs/transparent-videos).

## Creative review

Для разговора на улице первым выбором будет **Floating Website / left**. Портрет, знак и фраза опознаются в одном кадре. После первого просмотра нижний край панели привязан к началу первой секции: он больше не отрезает её элементы во время наезда.

Три сцены для короткого монтажа:

1. **Wordmark Emergence / left** — короткий вход на слове «сайт», с паузой на оригинальном знаке.
2. **Editorial Scroll** — перебивка, когда речь переходит к проектам. 16 секунд позволяют пройти весь индекс. Для короткой реплики оставь диапазон hero → annFlow.
3. **Typography Breakout** — единственный резкий скачок крупности. Лучше ставить на смысловой акцент, затем вернуться к лицу или выдержать отдельную финальную заставку.

Светлый адрес на светлом участке первого композита читался плохо. В финальный набор добавлен прозрачный дубль с тёмным адресом. Для скролла контрольные кадры теперь попадают на остановки, а встроенные потоки остаются на оригинальных постерах во время захвата.

MOV кодируется с входным форматом `yuva444p10le` и профилем ProRes 4444. FFprobe на этой машине показывает `yuva444p12le` при декодировании. Проверка отдельно извлекает плоскость alpha и ищет полностью прозрачные и непрозрачные пиксели в контрольном кадре. Контрастные превью сведены как straight alpha.

## Четыре сцены с более резким движением

```sh
npm run render:impact
npm run render:all -- --scene ShutterReveal --config configs/focus-annflow-25.json
```

Первая команда создаёт четыре прозрачных MOV, контактный лист `out/stills/impact-contact-sheet.png` и короткую вертикальную монтажную нарезку `out/previews/impact-reel.mp4`. Команда `npm run render:all` также включает эти четыре композиции. Они доступны в Studio с пресетом `dynamic` по умолчанию.

- **Wordmark Portal**. Блик проходит внутри оригинального SVG. Камера резко приближается к буквам, затем круглая маска раскрывает реальный мобильный hero.
- **Shutter Reveal**. Шесть вертикальных полос собирают hero. Полосы сдвигаются со встречными масками, открывая выбранный проект. По умолчанию — annFlow.
- **Project Orbit**. Реальные фрагменты трёх разделов расходятся на разных планах, с поворотом в перспективе. Выбранный раздел выходит вперёд и останавливается для чтения. По умолчанию — @arsenynn.
- **Match Cut**. Резкий наезд с кратким размягчением деталей переходит в крупный адрес. Тёмный адрес рассчитан на светлую съёмку. Для тёмной съёмки переключи `tone` на `light` в Studio или JSON.
