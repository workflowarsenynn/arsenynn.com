# Logos
LastUpdated: 2026-11-01 11:10 MSK

Исходники логотипов от владельца. Сюда кладутся оригиналы, оптимизированные версии для сайта появятся в `src/assets/` или `public/`.

Лучше всего подходит SVG, затем PNG с прозрачным фоном от 1000 px. Имена файлов: `arsenynn.svg`, `workflow.svg`, `bessmyslennost.svg`, `without-streaming.svg`, `annflow.svg`, `party-protocol.svg`, `travel-log.svg`.

Логотип не обязан попасть на страницу: `docs/brief.md` раздел 46 разрешает использовать только то, что улучшает композицию. Файл `@arsenynn` также нужен для favicon и OG image.
