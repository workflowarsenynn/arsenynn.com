4. Дождаться зелёного `test` на PR, явного «да», затем `gh pr merge N --repo workflowarsenynn/arsenynn.com --merge --match-head-commit <sha>`. Ветку не удалять.
5. Проверить живой сайт по маркеру из нового HTML (скрипты-примеры `wait-live-*.mjs` в scratchpad), плюс Playwright WebKit с профилем iPhone 13.
6. `git fetch origin main`, затем `git push origin <merge sha>:refs/heads/rollback/phase-N`. Записать фазу в `docs/implementation_plan.md` (Status «последняя фаза N», список Rollback) и `docs/handoff.md` («Последняя: rollback/phase-N»), обновить `LastUpdated`, commit, push: запись уедет со следующим PR.

Подводные камни цикла:
- Bash-guard отклоняет сложные команды с переменными, циклами, `cd` в чужие папки, `sudo` внутри строк. Писать скрипты в файл и запускать `python3 file` / `node file` / `ssh host 'bash -s' < file`.
- `cd` в параллельных вызовах может не сохраниться: всегда абсолютные пути, `git -C <worktree>`.
- CI `test` обычно 2–3 минуты. Однажды завис на `playwright install` больше 7 минут: `gh run cancel` и `gh run rerun` своего запуска помогли.
- Deploy Pages однажды упал по таймауту 10 минут на `syncing_files` (таймаут 30 минут в `deploy.yml` не сработал): `gh run rerun <id> --failed` помог за 4 минуты.
- Не опрашивать CI в цикле. Проверять статус по одному разу, между проверками делать полезную работу (повторы тестов, подготовка проверок).
- Тест свайпа раньше падал в ~2,5% запусков из-за постов с аудио: исправлено (PR 47). Если тест «случайно» падает, искать настоящую причину, гонять `--repeat-each`.
